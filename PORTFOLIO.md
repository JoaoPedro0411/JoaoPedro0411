## Projetos selecionados

### NutriFit — sistema web acadêmico

[Repositório no GitHub](https://github.com/JoaoPedro0411/Nutrifit_JP_GL)

Aplicação web desenvolvida em dupla para acompanhamento nutricional, treinos, agendamentos e hidratação. O sistema organiza regras e acesso a dados em camadas e oferece cadastro, login, dashboard e operações CRUD.

**Tecnologias:** Java 17, Spring Boot, Spring Security, Spring Data JPA, Thymeleaf, H2, MySQL e Maven.

**O que demonstra:** desenvolvimento de aplicação web com Java, persistência via JPA, organização entre controllers, serviços e repositórios, e implementação de fluxos de autenticação e gestão de dados.

### Shop API — aplicação full stack acadêmica em equipe

[Repositório no GitHub](https://github.com/Manihuts/trabalho-fullstack)

Trabalho final de Full Stack desenvolvido em equipe. Participei da implementação da autenticação com JWT e permissões de administrador, de endpoints da API e de fluxos do frontend para autenticação e operações com produtos. A aplicação contempla cadastro e login, gestão de produtos e inventário, além de operações de compra e venda.

**Tecnologias:** C#, ASP.NET Core Minimal API, Entity Framework Core, SQLite, JWT, React e Bootstrap.

**O que demonstra:** desenvolvimento de API com .NET, integração com persistência relacional, autenticação por token, autorização baseada em permissões e integração entre backend e frontend.

**Status:** projeto acadêmico em equipe; alguns fluxos do frontend ficaram parcialmente concluídos. O repositório pertence ao integrante que o mantém; a descrição acima se limita à minha participação registrada nos commits.

### API de carteira de investimentos — backend REST

[Repositório público no GitHub](https://github.com/JoaoPedro0411/carteira-investimentos-api)

API acadêmica para cadastro e autenticação de usuários, operações de carteira, histórico de transações e consulta de cotações externas.

**Tecnologias:** Node.js, Express, Sequelize, MySQL, Passport, JWT, bcrypt e Brapi.

**O que demonstra:** construção de API REST, organização em controllers e serviços, persistência relacional, autenticação e integração com serviço externo.

**Limitação conhecida:** projeto acadêmico; validações, cobertura de testes e revisão de segurança devem ser ampliadas antes de qualquer uso além de demonstração.

### Dashboard de Energia Solar — visualização de dados

[Repositório no GitHub](https://github.com/JoaoPedro0411/dashboard-energia-solar)

Dashboard interativo para explorar dados de usinas solares em oito estados norte-americanos. O usuário seleciona um indicador e compara os valores em um gráfico de barras, com acesso à tabela de dados.

**Tecnologias:** Python, pandas, Plotly, Dash, Dash Bootstrap Components e Dash AG Grid.

**O que demonstra:** leitura de CSV com pandas, visualização interativa, interface web com callbacks e organização de uma aplicação de dados.

**Limitação conhecida:** o conjunto disponível contém apenas oito estados e não registra fonte nem período de referência; portanto, serve para demonstrar a implementação, não para sustentar conclusões atuais sobre o setor.
